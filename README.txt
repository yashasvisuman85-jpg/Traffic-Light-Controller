# Verilog Traffic Light Controller

## Project Overview
A digital traffic light controller designed using Verilog HDL. The controller cycles through green, yellow, and red states using a clock-driven finite state machine (FSM).

## Tools Used
- Verilog HDL
- EDA Playground
- Icarus Verilog Simulator
- EPWave Waveform Viewer

## Features
- Three-state traffic light sequence
- Clock-driven state transitions
- Reset functionality
- Testbench-based functional verification
- Waveform inspection

## Verification
The testbench checks the expected green, yellow, and red output sequence. All sequence checks passed in simulation.

## Learning Outcomes
- Verilog modules and signal declarations
- Sequential and combinational logic
- Finite state machines
- Clock and reset behavior
- Simulation, testbenches, and waveform analysis

## Future Improvements
- Parameterized light durations
- Pedestrian crossing request
